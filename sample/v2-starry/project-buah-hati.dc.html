The problem

Judging avocado ripeness by eye is unreliable, and connectivity at markets and kitchens can't be assumed — the classifier needed to run entirely on-device, fast, with no network round-trip.

What I built

I designed and implemented the data engineering and ML pipeline: cleaning and preprocessing the ripeness dataset, and building automated object-detection annotation to speed up labeling. The trained model was converted and deployed with CoreML for on-device inference.

The app itself is built with SwiftUI, SwiftData for local persistence, and Vision for camera capture — giving an offline-first experience with low-latency results, no server dependency required.
